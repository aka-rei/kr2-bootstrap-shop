# СВЕТ: магазин светильников на Bootstrap

Контрольная работа №2 по дисциплине «Фронтенд и бэкенд разработка».

**Тема:** «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

**ФИО:** Филиппов К.А.

**Группа:** ЭФБО-13-25.

**Репозиторий:** https://github.com/aka-rei/kr2-bootstrap-shop

## О проекте

Bootstrap-версия магазина «СВЕТ». Содержание, навигация и организация страниц
согласованы с КР1: сохранены пять страниц, исходные тексты, изображения, цены,
категории, контактная информация и общая таблица характеристик.
Разметка сетки и компонентов выполнена средствами Bootstrap для КР2.

Проект работает самостоятельно: все изображения, CSS и JavaScript находятся
внутри репозитория.

| Из КР1 сохранено | Реализация в КР2 |
| --- | --- |
| Главная: «Настольные светильники», преимущества, популярные товары, контакты | Bootstrap-сетка `row`, `col-*`, `g-*`, карточки `card` |
| Пять пунктов меню: Главная, Каталог, Товары, Заявка, Контакты | `navbar` с раскрывающимся мобильным меню |
| Каталог с боковой панелью и разделами «Для работы» / «Для дома» | Адаптивные колонки, `card`, `badge`, рабочие фильтры питания |
| Три товара на одной странице, якоря `#dome`, `#line`, `#point` | Статические блоки товаров на Bootstrap-сетке |
| Общая таблица: высота, мощность, питание | `table`, `table-striped`, `table-responsive`, прежние значения |
| Кнопки «Оставить заявку» и модальное окно | Bootstrap `modal` с выбранной моделью |
| Поля заявки и согласие | `form-control`, `form-select`, `input-group`, `form-check` |
| Контакты `hello@svet.example` и +7 (000) 000-00-00 | Отдельная `contacts.html`, адаптивная сетка |
| Зелёная палитра, шрифт Segoe UI, изображения и общий характер оформления | Фирменные дополнения в `css/custom.css` |

Модели: «Купол» — 8 900 ₽, «Линия» — 6 400 ₽, «Точка» — 4 700 ₽.
Товары, характеристики, цены и контакты демонстрационные.
Реальной продажи, сервера и отправки заявок нет.

## Просмотр

Сайт открывается через `index.html` в браузере. Установка, сборка и интернет не нужны.
Также поддерживается запуск через локальный HTTP-сервер.

## Подключение Bootstrap

**Bootstrap 5.3.8 подключён локально**, без CDN, из `vendor/bootstrap/`.
Используется официальная compiled-версия из npm-пакета `bootstrap@5.3.8`.
Рядом сохранена MIT-лицензия. Bundle содержит необходимые зависимости.

На всех пяти страницах соблюдён порядок:

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js" defer></script>
<script src="js/main.js" defer></script>
```

`custom.css` сохраняет оформление КР1 поверх Bootstrap: цвета, размеры изображений,
фирменные блоки и адаптивные уточнения. Собственная CSS-сетка из КР1 не переносится:
расположение колонок и отступы сетки задаёт Bootstrap.

## Bootstrap-компоненты

- Сетка: `container`, `row`, `col-12`, `col-md-6`, `col-lg-3`, `col-lg-4`, `col-lg-8`, `col-lg-9`, `g-4`.
- Навигация: `navbar`, `navbar-expand-md`, `collapse` на всех страницах.
- Товары: `card`, `card-body`, `card-img-top`, `badge`, `btn-primary`.
- Форма: `form-control`, `form-select`, `input-group`, `form-check`, `btn-outline-secondary`.
- Сообщения: `alert` для пояснения формы, результата проверки и пустого каталога.
- Модальное окно: `modal`, `modal-dialog`, `modal-content`, `btn-close` на странице товаров.
- Дополнительный компонент: `accordion` в разделе «Вопросы и ответы» на главной.
- Таблица: `table`, `table-striped`, `table-responsive` на странице товаров.

## Самостоятельные доработки

1. Локальные файлы Bootstrap: просмотр без интернета.
2. Фильтры каталога: поиск по названию без учёта регистра и различий «е/ё»,
   назначение, питание («От сети» / «Аккумулятор»), максимальная цена.
   Если питание не выбрано, показаны все модели; два чекбокса означают оба типа питания.
3. Сортировка по цене и названию внутри каждой категории. Разделы «Для работы»
   и «Для дома» сохраняют структуру КР1; пустые разделы скрываются.
   Добавлены счётчик, пустое состояние и сброс фильтров.
4. Окно заявки доступно у всех трёх моделей и передаёт выбранный товар в форму
   через `order.html?product=line` и аналогичные ссылки.
5. В форме добавлены количество 1–10, пересчёт суммы и блок «Ваш выбор».
   Сохранены исходные имена полей `name`, `email`, `phone`, `product`, `comment`, `consent`.
6. Встроенная проверка браузера и `setCustomValidity`: обязательные поля,
   email, минимум две буквы в имени и 10 цифр телефона после +7.
7. Accordion с ответами, мобильное меню, видимый клавиатурный фокус,
   skip-link, `aria-live` для счётчика и суммы, поддержка reduced motion.

После корректного заполнения форма показывает учебное подтверждение.
Данные не отправляются по сети и не сохраняются. HTML-метод `dialog`
предотвращает обычную отправку при отключённом JavaScript.
Сброс очищает контакты и возвращает количество 1, сохраняя модель из ссылки.

Ссылки вида `product.html#dome` работают без JavaScript. Старые ссылки КР2
вида `product.html?product=dome` поддерживаются и переводят к соответствующему блоку.
